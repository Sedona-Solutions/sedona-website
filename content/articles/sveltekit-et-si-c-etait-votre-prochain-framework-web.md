## **Vous hésitez encore sur le framework de votre prochain projet web ? Et si la réponse s'appelait SvelteKit ?**

Il y a un an, forts de notre expérience sur Svelte, nous avons fait le pari de SvelteKit sur nos projets. Aujourd'hui, la techno est passée en version 1.0 stable — le bon moment pour un vrai retour d'expérience, sans filtre.

### **Au menu de cet apérocode** : 

(30 min, sans prérequis technique — juste de la curiosité)

Une intro à SvelteKit, puis un focus concret sur les gains que nous avons mesurés selon le type de projet.

* Productivité — développer plus vite, avec moins de code
* Maintenance — un projet plus simple à faire vivre dans le temps
* Lisibilité — un code plus clair, plus facile à reprendre
